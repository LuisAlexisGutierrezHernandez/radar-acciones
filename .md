# 📈 AI Stock Predictor Pro

Aplicación web de predicción bursátil con **Machine Learning** (KNN + XGBoost) usando indicadores técnicos.

## 🚀 Características
- Descarga automática de datos desde Yahoo Finance
- Cálculo de indicadores: SMA, RSI, rangos relativos
- Comparativa KNN vs XGBoost vs Baseline
- Señales de trading: **ALCISTA / BAJISTA / LATERAL**
- Visualizaciones interactivas con Plotly
- Importancia de features por ticker

## 🛠️ Stack
`Streamlit` · `yfinance` · `scikit-learn` · `xgboost` · `plotly` · `pandas`

## 📦 Deploy en Streamlit Cloud
1. Sube estos archivos a un repo de GitHub
2. Entra a [share.streamlit.io](https://share.streamlit.io)
3. Conecta tu repo y selecciona `app.py` como entry point
4. Presiona **Deploy**
